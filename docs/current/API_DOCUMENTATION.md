# Legacy API Documentation

**Canonical reference:** [`/API_DOCUMENTATION.md`](../../API_DOCUMENTATION.md) at the repo root.

That file is the single source of truth for the legacy HTTP contract (`src/routes/`, `{ success, data, error }` envelope, session cookies). Update it when changing legacy routes.
