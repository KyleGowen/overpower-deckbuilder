# Future Feature Proposals

This directory holds proposed Excelsior product improvements that are useful enough to preserve, but not yet approved for implementation. Files in this directory should describe future behavior, design intent, open questions, and likely implementation areas without changing the current source of truth for shipped behavior.

Use `docs/current/` for features that exist today. Move or rewrite a proposal into `docs/current/` only after the feature ships.

## Index

| Proposal | Status | Summary |
|---|---|---|
| [Deck Editor Add Cards Right Pane List View Toggle](deck-editor-add-cards-right-pane-list-view-toggle.md) | Proposed | Adds an optional compact/list presentation for the Add Cards result pane so users can scan names, text cues, and counts without replacing the card-first default grid. |
